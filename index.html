COMMANDES SPÉCIFIQUES "gsh"

Ce sont les seules commandes propres à GameShell pour piloter la progression :

gsh goal

Affiche le texte et l'objectif de la mission courante

gsh check

Vérifie si la mission est réussie et passe à la suivante

gsh exit

Sauvegarde l'avancement et quitte le jeu proprement

REPRISE DE PARTIE (SAUVEGARDE)

Important

Lorsque vous exécutez la commande gsh exit, le jeu génère automatiquement un fichier nommé gameshell-save.sh.

Pour reprendre votre partie la séance suivante, tapez :

bash gameshell-save.sh

⚠️ Ne relancez pas gameshell.sh si vous avez déjà une sauvegarde, sinon vous repartirez du début !

METHODOLOGIE : COMMENT RÉDIGER ET RENDRE VOTRE DOCUMENT

Suivez rigoureusement ces consignes pour obtenir la note maximale.

ÉTAPE 1

Création du Google Doc

Nommez votre document avec le format exact requis par le professeur :

GameShell + Nom + Prénom + Classe

Exemple: GameShell_DUPONT_Jean_1CIEL

ÉTAPE 2

Structure de chaque Mission

Pour chaque niveau complété, vous devez indiquer :

  • Numéro de Mission : ex: Mission 5
  • Commandes utilisées : ex: cd / rm / ls
  • Explication courte : Explication en 1 phrase.
  • Capture d'écran : Montrant gsh check validé.
ÉTAPE 3

Export PDF & Dépôt

Avant la date limite de l'évaluation finale :

  • Allez dans Google Doc > Fichier > Télécharger > Document PDF (.pdf)
  • Déposez le fichier PDF final dans votre devoir Google Classroom.
